# موقع مطابخ منى للإعاشة والتموين

الموقع الرسمي لشركة منى لخدمات الإعاشة. موقع ثابت (Static) باللغة العربية واتجاه RTL، مبني بحيث تُضاف اللغة الإنجليزية لاحقًا دون إعادة بناء.

المصدر المعتمد لجميع بيانات الشركة: **الملف التعريفي للشركة (1448هـ)**.

---

## التقنيات المستخدمة

| العنصر | التقنية | السبب |
|---|---|---|
| إطار العمل | [Astro](https://astro.build) 7.3.8 | يُنتج HTML ثابتًا سريعًا دون إطار JavaScript في المتصفح؛ مناسب لموقع تعريفي |
| الخطوط | Noto Kufi Arabic (العناوين) و IBM Plex Sans Arabic (النصوص) | مستضافة محليًا عبر Fontsource، دون الاعتماد على خوادم خارجية |
| الأيقونات | Lucide (رخصة ISC) | تُدرج كـ SVG وقت البناء |
| الصور | خدمة الصور المدمجة في Astro (sharp) | تحويل تلقائي إلى AVIF/WebP وتوليد مقاسات متعددة |
| التنسيق | CSS أصلي بمتغيرات (Design Tokens) | دون مكتبات تنسيق إضافية |

لا توجد قاعدة بيانات أو نظام دخول أو خادم خلفي.

## التشغيل

**المتطلبات:** Node.js بالإصدار 22.12 أو أحدث.

```bash
npm install        # تثبيت الحزم (مرة واحدة)
npm run dev        # خادم التطوير: http://localhost:4321
```

> **على ويندوز:** إذا ظهرت رسالة `running scripts is disabled on this system` في PowerShell، استخدم `npm.cmd` بدل `npm` (مثل `npm.cmd install` و`npm.cmd run dev`)، أو شغّل الأوامر من موجه الأوامر `cmd`.

أوامر إضافية:

```bash
npm run build      # بناء النسخة النهائية في المجلد dist/
npm run preview    # معاينة النسخة النهائية محليًا
npm run check      # فحص الأنواع والأخطاء
```

## استبدال الصور والشعار

### الصور
1. ضع الصورة في المجلد المناسب داخل `src/assets/images/`.
2. افتح `src/config/images.ts` وعدّل سطر `import` المقابل ليشير إلى الملف الجديد، وحدّث النص البديل `alt`.
3. العناصر النائبة تظهر حيث تكون القيمة `src: null` — استبدلها بالصورة المستوردة.

لا حاجة لضغط الصور يدويًا؛ يتولى Astro ذلك عند البناء. يُفضل أن يكون عرض الصورة 1600 بكسل على الأقل.
نسب الأبعاد ثابتة في التصميم، لذا تُقص الصور تلقائيًا بشكل متسق.

**ملاحظة:** الصور الحالية مستخرجة من صفحتي «معرض المطبخ» في الملف التعريفي ودقتها منخفضة (نحو 670 بكسل). استبدالها بالأصول عالية الدقة سيحسّن المظهر بوضوح.

### إضافة صور إلى المعرض
في `src/config/images.ts` استورد الصورة ثم أضف عنصرًا إلى المصفوفة `gallery` مع التصنيف المناسب:
`kitchen` (المطبخ)، `packing` (التجهيز والتغليف)، `team` (فريق العمل)، `facility` (المنشأة والنقل)، `meals` (الوجبات).

### الشعار
- الشعار مستخرج من ملف الشعار الرسمي المرفق (PNG شفاف). الملف: `src/assets/images/brand/logo.png`.
- لاستبداله: ضع النسخة الجديدة بالاسم نفسه. يُفضل ملف SVG أو PNG شفاف عالي الدقة.
- الأيقونات المفضلة في `public/` (favicon.ico, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png) مولّدة من رمز الشعار؛ تُعاد توليدها عند تغيير الشعار.
- صورة المشاركة على وسائل التواصل: `public/og-image.png` (1200×630).

## تحديث المحتوى وبيانات التواصل

| ما تريد تعديله | الملف |
|---|---|
| الهاتف، البريد، العنوان، الإحداثيات، حسابات التواصل الاجتماعي | `src/config/site.ts` |
| نصوص أي صفحة | `src/content/ar/<الصفحة>.ts` |
| سجل الخبرات (يحدّث أرقام الصفحة الرئيسية وصفحة الخبرات تلقائيًا) | `src/content/ar/experience.ts` |

| عناصر القائمة | `src/config/navigation.ts` |
| الألوان والخطوط | المتغيرات في أعلى `src/styles/global.css` |

حسابات التواصل الاجتماعي تظهر تلقائيًا في التذييل عند إضافة روابطها في `social` داخل `src/config/site.ts`.

## نموذج طلب عرض السعر

النموذج حاليًا في **وضع تجريبي** (`contactForm.mode = 'demo'`):
- يتحقق من الحقول (الاسم، جوال سعودي، بريد، الخدمة، العدد).
- **لا يُرسل أي بيانات**، ويُظهر للزائر رسالة واضحة بذلك مع زرين: إرسال الطلب عبر البريد (رسالة معبأة مسبقًا) أو الاتصال.

لتفعيل الإرسال الفعلي:
1. أنشئ نموذجًا لدى خدمة نماذج تقبل JSON (مثل Formspree أو Web3Forms أو خادم خاص بالشركة).
2. في `src/config/site.ts`: اضبط `mode: 'endpoint'` و `endpoint: 'https://...'`.
3. اختبر الإرسال فعليًا قبل النشر.

## إضافة اللغة الإنجليزية لاحقًا

1. أضف `'en'` إلى `locales` في `astro.config.mjs` وفي `src/i18n/locales.ts` (مع `dir: 'ltr'` و `pathPrefix: '/en'`).
2. أنشئ `src/content/en/` بنفس ملفات `src/content/ar/`، وأضفها في `src/content/index.ts`.
3. أضف قاموس `en` في `src/i18n/ui.ts` وعناوين القائمة في `src/config/navigation.ts`.
4. أنشئ `src/pages/en/` بنفس صفحات `src/pages/` مع `locale="en"`.

التخطيط يعتمد على خصائص CSS المنطقية (inline/block)، لذا ينعكس تلقائيًا من اليمين لليسار. الأيقونات الاتجاهية تنعكس تلقائيًا كذلك.

## النشر على GitHub Pages

المشروع مُعدّ للنشر التلقائي عبر GitHub Actions (الملف `.github/workflows/deploy.yml`):

1. أنشئ مستودعًا جديدًا على GitHub (عامًا إذا كان الحساب مجانيًا، لأن GitHub Pages في الخطة المجانية يعمل على المستودعات العامة فقط).
2. ارفع المشروع إلى الفرع `main`.
3. من إعدادات المستودع: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
4. كل دفع (push) إلى `main` يبني الموقع وينشره تلقائيًا. تُتابَع الحالة من تبويب **Actions**.

يحدد سير العمل عنوان الموقع والمسار الأساسي تلقائيًا:

| الحالة | عنوان الموقع |
|---|---|
| مستودع باسم آخر (مثل `muna-catering-website`) | `https://<الحساب>.github.io/muna-catering-website/` |
| مستودع باسم `<الحساب>.github.io` | `https://<الحساب>.github.io/` |
| وجود ملف `public/CNAME` يحتوي نطاقًا | النطاق المكتوب في الملف |

### ربط نطاق خاص لاحقًا
1. أنشئ الملف `public/CNAME` يحتوي سطرًا واحدًا بالنطاق، مثل `www.domain.sa`.
2. أضف سجل DNS من نوع CNAME يشير إلى `<الحساب>.github.io`.
3. أدخل النطاق في **Settings ← Pages ← Custom domain** وفعّل **Enforce HTTPS**.

### استضافة أخرى
الموقع ثابت بالكامل؛ يمكن رفع محتوى `dist/` إلى أي استضافة ثابتة. عند البناء يدويًا تُضبط المتغيرات `SITE_URL` و`BASE_PATH` (انظر `.env.example`).

### تجربة المسار الفرعي محليًا
```bash
BASE_PATH=/muna-catering-website npm run build
npm run preview
```
ثم افتح `http://localhost:4321/muna-catering-website/`.

> خريطة Google المضمّنة في صفحة التواصل تُحمَّل من خوادم Google عند فتح الصفحة.

- `npm run build` و `npm run check` دون أخطاء.
- فحص آلي (Playwright/Chromium) لكل الصفحات على عروض 1440 و768 و390 بكسل: لا تمرير أفقي، ولا أخطاء في وحدة التحكم، وكل الروابط الداخلية والمراسي تعمل.
